# WD2 ctOS intro (MK12) — frame analysis notes

Source: "Watch Dogs 2 - ctOS Introduction Scene" (120s), frame-sampled 2026-07-03.
Reference for the xiaoOS Zoom-In. Spirit, not copy; single-cyan palette still rules.

## Structure (three acts)

1. **The system (0–35s)** — giant white Helvetica stat-cards ("2013", "hundred",
   "6.4 billion") intercut with satellite-photo city maps: red aircraft + dashed
   routes, cyan infrastructure threads along streets, tiny mono coordinates,
   ctOS chip pinned top-right. Vertical code columns (black-on-white). Grid
   pixel-shatter for the blackout. Radar circles with city labels; dashed lines
   crossing state borders; dissolving-pixel USA.
2. **You (35–75s)** — "BIG BROTHER" type card; confetti of tiny documents
   aggregating into a profile; stacks of pixelated portraits ("digital profile
   of YOU", "sold" in magenta); X-ray wireframe scans of objects (doll, living
   room); N. Oak St. neighborhood wireframe with car pin + VIN plate breakdown;
   censored brain scan; pixelated face + insurer/health denial copy;
   acid-green inverted card ("less valuable than the data you produce").
3. **The resistance (75–100s)** — type stack ("this is the new reality"),
   `execute? Y` prompt on WHITE, ASCII-art skull, then explosion into acid
   zine collage (DedSec) — counterculture takeover.

## Techniques adopted for xiaoOS

- **Kinetic type narration**: oversized display-type cards riding the flight
  (crop allowed, two-line offset stacks, fast in/out with parallax).
- **White inversion flash** at the capture beat (their execute?/white-page flips).
- **Document confetti → profile**: small white rects converging into the
  profiler card ("aggregating your file").
- **Cyan data routes**: dashed lines threading the city streets, animated
  offset — the system's arteries (their cyan infrastructure threads).

## Noted but NOT adopted (charter conflicts / later candidates)

- Red threat accent (aircraft, denial X's) — violates single-cyan rule.
- Magenta commerce accent ("sold") — same.
- Satellite-photo textures — breaks the procedural/vector language.
- Pixel-shatter grid transition — candidate for a later skip/glitch beat.
- VIN-style plate breakdown — candidate for the profiler card fields.
- Acid zine collage — wrong register for a hiring-first portfolio.
